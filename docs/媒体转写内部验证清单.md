# 媒体转写内部验证清单

## 目标

先在不改页面的前提下，验证音频/视频 -> 逐字稿 -> 现有纪要分析链路是否能稳定跑通。

## 前提

- 已配置真实模型
- 若测视频，机器上已安装 `ffmpeg`
- 准备 1 个音频文件、1 个视频文件、1 份已知逐字稿

## 验证项

### 0. 一键内部烟测

命令：

```bash
python3 -B evals/run_media_smoke.py
```

检查：

- 是否能生成音频样例
- 是否能跑通媒体转写到纪要输出
- 是否能输出 `minutes.json`、`minutes.md`、`minutes.html`

### 1. 音频转写

命令：

```bash
python3 -m src.pipeline /path/to/audio.mp3 -o out/audio-test
```

检查：

- 能否输出 `minutes.json`
- 能否输出 `minutes.md`
- `transcript.cleaned.json` 是否有分段

### 2. 视频转写

命令：

```bash
python3 -m src.pipeline /path/to/video.mp4 -o out/video-test
```

检查：

- 能否先抽音轨
- 能否进入 ASR
- 最终纪要是否正常生成

### 3. 逐字稿对照

命令：

```bash
python3 -m src.pipeline /path/to/transcript.json -o out/transcript-test
```

检查：

- 当前分析链路是否稳定
- 分类是否正确
- `议题 / 结论 / 待办` 是否完整

## 通过标准

- 音频和视频都能跑到纪要输出
- 失败时错误可读
- 分析结果不退化为空模板
- 逐字稿输入与媒体输入输出形态一致
