# 操作手册｜会议纪要转写

## 1. 产品简介

会议纪要转写是一个将逐字稿转换为结构化会议纪要的产品。

当前输出重点为：

- 议题
- 结论
- 待办

系统会基于逐字稿自动识别会议类型，按模板生成纪要，并通过规则校验尽量降低幻觉内容。

## 2. 适用范围

当前版本适用于：

- 已经有逐字稿内容的会议整理
- 会后快速生成纪要
- 对纪要结构化输出有明确要求的场景

当前版本不适用于：

- 原始音频转文字
- 实时会议记录
- 多人协作权限管理
- 自动同步到任务系统

## 3. 使用前准备

### 3.1 启动方式

在项目根目录执行：

```bash
python3 -m src.server
```

默认访问地址：

```text
http://127.0.0.1:8000
```

如果 `8000` 端口被占用，可改用其他端口：

```bash
python3 -m src.server 8010
```

### 3.2 模型准备

本产品调用真实模型生成纪要，不提供 mock 结果。

可通过两种方式配置模型：

- 启动前通过环境变量配置
- 登录后在页面右上角通过“模型配置”填写

常见环境变量示例：

```bash
export MINUTES_LLM_PROVIDER=openai_compatible
export MINUTES_LLM_MODEL=your-model-name
export MINUTES_LLM_BASE_URL=https://api.openai.com/v1
export MINUTES_LLM_API_KEY=your-api-key
```

## 4. 登录与注册

### 4.1 注册账号

首次进入页面时，需要先注册或登录。

注册步骤：

1. 进入登录浮层
2. 点击“邮箱注册”
3. 输入邮箱地址
4. 输入密码
5. 再次输入密码
6. 完成滑块验证
7. 保持免责声明勾选
8. 点击“注册并进入”

### 4.2 登录账号

登录步骤：

1. 点击“邮箱登录”
2. 输入邮箱地址
3. 输入密码
4. 完成滑块验证
5. 保持免责声明勾选
6. 点击“登录并进入”

### 4.3 当前账号体系说明

当前版本已支持基础账号隔离：

- 纪要数据按用户隔离
- 模型配置按用户隔离
- 登录后只能看到自己的纪要

## 5. 首页说明

登录后进入纪要库首页。

首页主要区域包括：

- 账号信息
- 退出按钮
- 模型配置
- 创建纪要
- 纪要卡片列表

纪要卡片会展示：

- 标题
- 状态
- 会议类型
- 最近更新时间

## 6. 模型配置

点击右上角“模型配置”后，可填写模型信息。

当前支持配置项包括：

- Provider
- Model
- Base URL
- API Key
- Temperature
- Max Tokens
- Timeout Seconds

建议使用流程：

1. 先填写模型信息
2. 点击“保存配置”
3. 点击“测试连接”
4. 确认连接成功后，再开始生成纪要

## 7. 创建纪要

### 7.1 新建纪要

点击“创建纪要”后，会进入纪要编辑页并自动创建一条草稿。

### 7.2 输入逐字稿

当前支持两种输入方式：

- 直接粘贴原始逐字稿文本
- 上传文件

目前上传支持：

- `.json`
- `.md`

### 7.3 生成纪要

输入逐字稿后：

1. 点击“纪要生成”
2. 系统开始调用模型处理
3. 成功后右侧展示纪要内容

系统处理流程为：

`输入 -> 清洗/润色 -> 分类 -> 模板选择 -> 生成 -> 校验 -> 导出`

## 8. 纪要查看与编辑

生成完成后，可在详情页继续查看和编辑。

支持的操作包括：

- 修改纪要标题
- 编辑纪要正文
- 返回纪要库
- 重新生成

标题限制：

- 最长 20 个字符

## 9. 纪要状态说明

当前常见状态包括：

- 草稿
- 纪要已生成
- 纪要生成失败

当生成失败时，页面会展示失败原因，便于判断是模型配置问题还是内容本身未达到生成标准。

## 10. 下载与导出

生成成功后，可通过右上角下载按钮导出。

当前支持：

- 下载为 Word
- 下载为 JSON
- 下载为 Markdown

## 11. 删除纪要

在首页卡片上悬停可看到删除按钮。

删除步骤：

1. 点击删除按钮
2. 在弹窗中确认
3. 删除后不可恢复

## 12. 会议类型说明

系统当前支持的会议类型包括：

- `project_sync`
- `decision_review`
- `issue_triage`
- `brainstorming`
- `interview_research`
- `general_meeting`

会议类型用于：

- 选择纪要模板
- 调整抽取重点

不会改变真实性和校验规则。

## 13. 输出原则

系统在生成纪要时遵循以下原则：

- 不编造结论
- 不编造待办
- 不编造负责人
- 不编造时间
- 不编造数字
- 没有明确结论时，不强行写成已达成一致

## 14. 常见问题

### 14.1 页面打开后无法生成

可能原因：

- 未配置模型
- 模型连接测试未通过
- 当前是 `file://` 打开，而不是通过本地服务访问

建议检查：

- 是否通过 `python3 -m src.server` 启动
- 是否已保存模型配置
- 是否已测试连接成功

### 14.2 登录或注册按钮不可点击

请检查：

- 是否完成滑块验证
- 是否勾选免责声明

### 14.3 页面没有显示最新修改

可能原因：

- 浏览器缓存未刷新
- 本地服务未重启
- 服务器未同步最新前端文件

### 14.4 生成失败

可能原因：

- 模型配置错误
- API Key 无效
- 输入内容不足以形成纪要
- 校验后内容被过滤

## 15. 数据存储说明

当前版本的数据存储位置：

- 用户账号：`data/auth/users.json`
- 登录会话：`data/auth/sessions.json`
- 用户纪要：`data/minutes/<user_id>/`
- 用户模型配置：`data/configs/<user_id>/config.json`

## 16. 建议使用流程

建议按以下顺序使用：

1. 启动服务
2. 注册或登录账号
3. 配置模型
4. 测试模型连接
5. 创建纪要
6. 粘贴或上传逐字稿
7. 生成纪要
8. 检查并编辑结果
9. 下载导出
